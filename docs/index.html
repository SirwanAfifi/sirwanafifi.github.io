API reference

Sirwan Afifi public content API_

A small, read-only HTTP API for site discovery and published-post metadata. The base URL is https://sirwan.info and all endpoints use GET.

Request conventions

  • No authentication or API key is required.
  • JSON responses use UTF-8 and standard HTTP status codes.
  • Clients should cache successful responses for at least five minutes.
  • There are no write endpoints, pagination parameters, or webhooks.

Endpoints

GET

/api/site.json

Returns the site's identity, author, languages, authentication policy, and canonical discovery-resource URLs.

curl --fail --silent \
  https://sirwan.info/api/site.json

GET

/api/posts.json

Returns all non-draft posts, newest first. Each item includes title, language, dates, tags, canonical URL, and its explicit Markdown URL.

curl --fail --silent \
  https://sirwan.info/api/posts.json

Errors and formats

Unknown paths return a real 404 response with recovery links. Content pages support HTML and Markdown representations through HTTP Accept negotiation at the edge. An explicit request that accepts neither representation returns 406 Not Acceptable. JSON, XML, text, images, fonts, and other static assets keep their native media types and are not negotiated.

Machine-readable contract

The canonical OpenAPI 3.1 entry document is available at/openapi.json. Return to thedeveloper portal for the quickstart and live sandbox.
