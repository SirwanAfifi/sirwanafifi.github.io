# Sirwan Afifi

Sirwan Afifi is a senior software engineer building web applications for high-tech companies in the UK. He works across the modern web with Node.js, Deno, Next.js, React, TypeScript, and ASP.NET Core, and writes about the systems, tools, and experiments behind that work.

This personal engineering journal is published in English, Farsi, and Kurdish. It is designed to remain useful without JavaScript and provides explicit machine-readable discovery resources.
