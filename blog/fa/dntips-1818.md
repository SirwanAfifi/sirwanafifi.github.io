 </div> <p>در کلاس فوق خصوصیت یک alert را تعریف کرده‌ایم (از خاصیت TempDataKey جهت پاس دادن alert‌ها به view استفاده می‌کنیم).</p> <div>   <b>کلاس AlertStyles</b> <br/> </div> <div> <div align="left" dir="ltr">

کلاس فوق نیز جهت نگهداری اسامی کلاس‌های alert، مورد استفاده قرار می‌گیرد. قدم بعدی، استفاده از کلاس‌های فوق و انتقال alerts توسط <a href="https://www.dntips.ir/post/807">TempData </a>به داخل viewها می‌باشد. برای جلوگیری از زیاد شدن حجم کدهای تکراری داخل کنترلرها و همچنین به عنوان یک Best practice، یک کنترلر Base را برای اینکار تعریف می‌کنیم و متدهای موردنیاز را داخل آن می‌نویسیم:  <br/> </div> <div> <div align="left" dir="ltr">
<pre language="CSharp" name="code">public class BaseController : Controller&#10;{&#10;        public void Success(string message, bool dismissable = false)&#10;        {&#10;            AddAlert(AlertStyles.Success, message, dismissable);&#10;        }&#10;&#10;        public void Information(string message, bool dismissable = false)&#10;        {&#10;            AddAlert(AlertStyles.Information, message, dismissable);&#10;        }&#10;&#10;        public void Warning(string message, bool dismissable = false)&#10;        {&#10;            AddAlert(AlertStyles.Warning, message, dismissable);&#10;        }&#10;&#10;        public void Danger(string message, bool dismissable = false)&#10;        {&#10;            AddAlert(AlertStyles.Danger, message, dismissable);&#10;        }&#10;&#10;        private void AddAlert(string alertStyle, string message, bool dismissable)&#10;        {&#10;            var alerts = TempData.ContainsKey(Alert.TempDataKey)&#10;                ? (List&lt;Alert&gt;)TempData[Alert.TempDataKey]&#10;                : new List&lt;Alert&gt;();&#10;&#10;            alerts.Add(new Alert&#10;            {&#10;                AlertStyle = alertStyle,&#10;                Message = message,&#10;                Dismissable = dismissable&#10;            });&#10;&#10;            TempData[Alert.TempDataKey] = alerts;&#10;        }&#10;}</pre>
 </div>
از متدهایی که به صورت عمومی تعریف شده‌اند جهت ارسال پیام به view استفاده می‌کنیم. متد AddAlert نیز جهت ایجاد لیستی از پیام‌ها(Alert) مورداستفاده قرار می‌گیرد؛ زیرا ممکن است بخواهید هم زمان از چندین متد عمومی فوق استفاده کنید، یعنی چندین پیام را به کاربر نمایش دهید.  <br/> </div> <div> <hr/> </div> <div> <b>نکته: </b>در کد فوق از <a href="https://www.dntips.ir/post/1808">TempData</a>  جهت پاس دادن شیء alerts استفاده کرده‌ایم. TempData به صورت short-lived عمل می‌کند به دو دلیل: 1- بلافاصله بعد از خوانده شدن، حذف خواهد شد. 2- پس از پایان درخواست از بین خواهد رفت. از TempData جهت پاس دادن داده‌ها از درخواست فعلی به درخواست بعدی (redirect از یک صفحه به صفحه دیگر) استفاده می‌شود. یعنی در زمان redirect سعی می‌کند داده‌های بین redirectها را در خود نگه دارد. اگر از ViewBag و ViewData استفاده می‌کردیم داده‌های داخل آنها بلافاصله بعد از redirect شدن null می‌شدند.</div> <div>به طور مثال اکشن متد زیر را در نظر بگیرید:</div> <div> <div align="left" dir="ltr">
<pre language="CSharp" name="code">public ActionResult Index()&#10;        {&#10;            var userInfo = new&#10;            {&#10;                Name = "Sirwan",&#10;                LastName = "Afifi",&#10;            };&#10; &#10;            ViewData["User"] = userInfo;&#10;            ViewBag.User = userInfo;&#10;            TempData["User"] = userInfo;&#10;&#10;            return RedirectToAction("About");&#10;        }</pre>
 </div>
