<div class="postBody">در این مطلب، نحوه‌ی استفاده از افزونه‌ی Web Essentials جهت پردازش فایل‌های LESS را بررسی می‌کنیم. پیش‌تر مطالبی را در رابطه با <a href="https://www.dntips.ir/post/1570">CSS pre-processor</a>ها مطالعه کرده‌اید، <a href="http://lesscss.org/">LESS</a> نیز یک CSS pre-processor است، یا در واقع بهتر است بگوئیم یک زبان جهت پویا کردن CSS می‌باشد که در سال 2009 توسط Alexis Sellier به صورت سورس باز <a href="http://en.wikipedia.org/wiki/LESS_(stylesheet_language)">ایجاد شد</a>. یکی از خصوصیات جالب LESS نسبت به دیگر CSS preprocessorها، قابلیت کامپایل فایل‌های CSS به صورت real-time از طریق مرورگر توسط LESS.js می‌باشد.<div> <b> <br/> </b> </div> <div> <b>روش‌های استفاده از LESS در دات نت</b> </div> <div> <b>1- استفاده از SimpLESS</b> </div> <div> <a href="http://wearekiss.com/simpless">SimpLESS</a> تمام تغییرات فایل‌های CSS را مشاهده می‌کند و در نهایت به صورت خودکار آنها را به CSS کامپایل و همچنین miniy می‌کند. این روش مستقل از دات نت است و برای هر فایل LESSی جوابگو خواهد بود.</div> <div> <p> <img src="/img/dntips/1f255bbbe16149a8358a.png" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p> <b>2- استفاده از {}less.</b> </p> <p>Dotless یک پیاده سازی از کتابخانه جاوا اسکریپتی LESS برای دات نت می‌باشد. پکیج نیوگت DotLess را نیز می‌توانید از <a href="https://www.nuget.org/packages/dotless/">اینجا</a> دریافت کنید. بعد از اضافه شدن فایل‌های آن، یک ارجاع به dotless.core به پروژه تان اضافه خواهد شد. همچنین در فایل Web.Config در قسمت HttpHandler خط زیر اضافه خواهد شد:</p> <div align="left" dir="ltr">
<pre language="CSharp" name="code">&lt;add type="dotless.Core.LessCssHttpHandler,dotless.Core" validate="false" path="*.LESS" verb="*" /&gt;</pre>
 </div> <p>خط فوق یعنی به محض مواجه شدن با فایل LESS، پردازشگر فایل‌های LESS وارد عمل می‌شود. همچنین خط زیر نیز جهت پیکربندی به قسمت configSections در فایل Web.Config اضافه می‌شود:</p> <div align="left" dir="ltr">
<pre language="CSharp" name="code">&lt;section name="dotless" type="dotless.Core.configuration.DotlessConfigurationSectionHandler,dotless.Core" /&gt;</pre>
 </div> <p>همچنین اگر مایل بودید می‌توانید تنظیمات مربوط به فشرده سازی و caching را نیز فعال کنید:</p> <div align="left" dir="ltr">
<pre language="CSharp" name="code">&lt;dotless minifyCss="false" cache="true" /&gt;</pre>
 </div> <p> <b>3- استفاده از افزونه‌ی Web Essentials</b> </p> <p> <a href="http://vswebessentials.com/">Web Essentials</a> برای کامپایل فایل‌های LESS از کامپایلر node استفاده می‌کند. کار با این افزونه خیلی ساده است. کافی است پسوند فایل CSS موجود در پروژه تان را درون ویژوال استودیو، به less. تغییر دهید. با دوبار کلیک بر روی فایل، ویرایشگر فایل‌های LESS برای شما نمایش داده می‌شود، همزمان نیز فایل یک فایل CSS و یک نسخه از فایل CSS را به صورت فشرده، برایتان تولید می‌کند. خب، هر بار که فایل LESS را تغییر دهید، Web Essentials به صورت خودکار فایل‌های css. و min.css. را برایتان روز رسانی می‌کند.</p> <p> <img src="/img/dntips/f18321e7cf57783b4620.jpg" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p>خوب با کلیک بر روی فایل less، ویرایشگر فایل‌های less نمایش داده می‌شود که با تغییر فایل css می‌توانید پیش نمایش آنرا در سمت راست مشاهده کنید:</p> <p> <img src="/img/dntips/ff2cb3a3c833edc5501a.jpg" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p> <b>تعریف متغیر</b> </p> <p>با استفاده از syntax زیر می‌توانید متغیرهای خود را تعریف کنید:</p> <div align="left" dir="ltr">
<pre language="CSharp" name="code">@variable-name: variableValue;</pre>
 </div> <p>یکی از قابلیت‌های جالب در حین مقداردهی متغیرها به خصوص زمانیکه مقدار یک کد رنگی باشد، نمایش کادر انتخاب رنگ است، این کادر بلافاصله بعد از نوشتن علامت # در ابتدای مقدار متغیر نمایش داده می‌شود:</p> <p> <img src="/img/dntips/5ae8a9a5777c30ff4a4c.jpg" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p>به طور مثال با تعریف متغیر فوق هر جایی می‌توانیم برای تعیین رنگ از آن استفاده کنیم:</p> <div align="left" dir="ltr">
<pre language="CSharp" name="code">@primary-color: #ff6a00;&#10;body&#10;{&#10;    background-color: @primary-color;&#10;}</pre>
 </div> <p> <b>استفاده از توابع</b> </p> <p>LESS شامل تعداد زیادی <a href="http://lesscss.org/features/#features-overview-feature-functions">توابع</a> از پیش نوشته شده است که می‌توانید به راحتی از آنها استفاده کنید، توابعی از جمله کار با رنگ ها، اعمال ریاضی و غیره. استفاده از آنها خیلی ساده است. به طور مثال در کد زیر از تابع percentage جهت تبدیل 0.5 به 50% استفاده کرده ایم: </p> <div align="left" dir="ltr">
<pre language="CSharp" name="code">.myClass&#10;{&#10;    width: percentage(0.5);&#10;}</pre>
 </div> <p> <b>استخراج یک فایل</b> </p> <p>یکی دیگر از قابلیت‌های Web Essentials استخراج(Extract) یک فایل می‌باشد به طور مثال فایل LESS شما شامل متغیرهای زیر است:</p> <div align="left" dir="ltr">
<pre language="CSharp" name="code">@primary-color: #7BA857;&#10;@primary-color-light: #B6DE8F;&#10;@primary-color-lighter: #D3EFC3;&#10;@primary-color-lightest: #EFFAE6;&#10;@secondary-color: #AE855C;&#10;@text-color-light: #666666;&#10;@text-color-dark: #0444;</pre>
 </div> <p>به راحتی می‌توانید تعاریف فوق را درون یک فایل LESS دیگر با نام colors.less قرار دهید:</p> <p> <img src="/img/dntips/d778d79dd04a7ae5311b.jpg" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p> <img src="/img/dntips/75079a343df24434c113.jpg" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p> <b>تغییر تنظیمات پیش فرض Web Essentials</b> </p> <p>افزونه Web Essentials دارای یک قسمت جهت تغییر تنظیمات پیش فرض برای کار با LESS می‌باشد که با مراجعه به منوی Tools در ویژوال استودیو و سپس Options می‌توانید آنها را تغییر دهید:</p> <p> <img src="/img/dntips/fbaa771cf549bc6bf87b.jpg" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p>Auto-compile dependent files on save: توسط این گزینه می‌توانیم تعیین کنیم که فایل‌های که import کرده ایم تنها در صورتی که تغییر کرده و ذخیره شده باشند، در فایل CSS جاری کامپایل شوند.</p> <p>Compile files on build: توسط این گزینه می‌توانیم تعیین کنیم که فایل‌های less در زمان Build پروژه کامپایل شوند.</p> <p>Compile files on save: توسط این گزینه می‌توانیم تعیین کنیم که فایل‌های less در زمان ذخیره کردن پروژه کامپایل شوند.  </p> <p>Create source map files: اگر این گزینه True باشد <a href="http://www.html5rocks.com/en/tutorials/developertools/sourcemaps/">فایل map.</a> نیز تولید خواهد شد.</p> <p>Custom output directory: اگر می‌خواهید خروجی در پوشه‌ی موردنظر شما نمایش داده شود می‌توانید آدرس آن را تعیین کنید.</p> <p>Don't save raw compilation output: با فعال بودن این گزینه فایل CSS عادی ایجاد نخواهد شد.</p> <p>Process source maps: توسط این گزینه می‌توانید قابلیت‌های ویرایشگر فایل‌های source map را فعال یا غیرفعال کنید.</p> <p>Strict Math: با فعال بودن این گزینه LESS تمام اعمال ریاضی درون فایل CSS را پردازش خواهد کرد.</p> <p>Show preview pane: از این گزینه نیز جهت نمایش یا عدم نمایش preview window استفاده می‌شود.</p> </div></div>
