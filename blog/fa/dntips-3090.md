# نحوه‌ی استفاده از ViewComponent درون Controller

در ASP.NET Core یک View Component ، در نهایت خلاصه‌ایی از قابلیت‌هایی را ارائه میدهد که قرار است توسط یک کنترلر مدیریت شوند؛ زیرا پارامترهای یک View Component از طریق یک HTTP Request تامین نمی‌شوند. ی

<div class="postBody"><div>در ASP.NET Core یک <a href="https://www.dntips.ir/post/2461">View Component</a>، در نهایت خلاصه‌ایی از قابلیت‌هایی را ارائه میدهد که قرار است توسط یک کنترلر مدیریت شوند؛ زیرا پارامترهای یک View Component از طریق یک HTTP Request تامین نمی‌شوند. یعنی به صورت مستقیم از طریق درخواست‌های HTTP قابل دسترسی نیستند. فرض کنید در یک برنامه می‌خواهیم لیست کاربران سایت را نمایش دهیم تا با کلیک بر روی نام کاربر، امکان ویرایش کاربر انتخاب شده را داشته باشیم. با کلیک بر روی لینک مورد نظر، اطلاعات درخواست، به کنترلر UserManagerController و سپس اکشن متد Edit ارسال خواهد شد. در حالت عادی باید یک ViewComponent برای لیست کاربران و همچنین یک UserManagerController، برای ویرایش کاربر درون پروژه داشته باشیم:</div> <div align="left" dir="ltr" style="direction: ltr;"> </div> <div> <div align="left" dir="ltr" style="direction: ltr;"> </div> </div> <div> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="CSharp" name="code">public class UserListViewComponent : ViewComponent&#10;{&#10;    private readonly UserRepository repository;&#10;&#10;    public UserListViewComponent(UserRepository repository)&#10;    {&#10;        this.repository = repository;&#10;    }&#10;    public IViewComponentResult Invoke()&#10;    {&#10;        var users = repository.GetUsers().Take(10).ToList();&#10;        return View(model: users);&#10;    }&#10;}</pre>
 </div> <br/> </div> <div>ویووی کامپوننت فوق نیز به این صورت تعریف شده است:</div> <div> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="XML" name="code">@model IList&lt;User&gt;&#10;@foreach (var user in Model)&#10;{&#10;    &lt;li&gt;&#10;        &lt;a asp-controller="UserManager" asp-action="Edit" asp-route-id="@user.Id"&gt;@user.Name&lt;/a&gt;&#10;    &lt;/li&gt;&#10;}&#10;&lt;a class="btn btn-info" asp-controller="UserManager" asp-action="Index"&gt;More...&lt;/a&gt;</pre>
 </div> <br/> </div> <div>کنترلر UserManager نیز یک چنین تعریفی را دارد:</div> <div> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="CSharp" name="code">public class UserManagerController : Controller&#10;{&#10;    private readonly UserRepository repository;&#10;&#10;    public UserManagerController(UserRepository repository)&#10;    {&#10;        this.repository = repository;&#10;    }&#10;&#10;    public ViewResult Index()&#10;    {&#10;        var users = repository.GetUsers().ToList();&#10;        return View(users);&#10;    }&#10;&#10;    public ViewResult Edit(int id)&#10;    {&#10;        var user = repository.GetUsers().FirstOrDefault(u =&gt; u.Id == id);&#10;        return View(user);&#10;    }&#10;&#10;    [HttpPost]&#10;    public IActionResult Edit(User user)&#10;    {&#10;        repository.Edit(user);&#10;        return RedirectToAction("Index", "Home");&#10;    }&#10;}</pre>

همانطور که مشاهده می‌کنید، کنترلر UserManager و کامپوننت UserList، به ترتیب کار مدیریت و نمایش کاربران را انجام میدهند و منطقاً هر دو جزو قابلیت‌های User هستند. برای جلوگیری از تکرار کد، می‌توانیم کنترلر و ویو‌وکامپوننت فوق را با هم ادغام کنیم؛ در واقع می‌توانیم UserListViewComponent را درون UserManagerController تعریف کنیم. برای این کار کافی است فایل UserManagerController را اینگونه تغییر دهیم:<div> <div align="left" dir="ltr" style="direction: ltr;"> </div> <div align="left" dir="ltr" style="direction: ltr;">

 </div> <br/> <div>  </div> <div> <b>توضیحات:</b> </div> <div>همانطور که <a href="https://www.dntips.ir/post/2461">پیش‌تر</a> نیز بحث شده است، از ویژگی ViewComponent زمانی استفاده خواهد شد که کلاس موردنظر از کلاس پایه ViewComponent ارث‌بری نکرده باشد و همچنین نام کلاس به ViewComponent ختم نشده باشد. با تعیین پراپرتی Name، یک نام برای ViewComponent تعیین کرده‌ایم که در نهایت درون ویوو، توسط Component.Invoke@  قابل فراخوانی باشد. همچنین از آنجائیکه UserManagerController از کلاس پایه ViewComponent ارث‌بری نکرده است، در نتیجه به اشیاء IViewComponentResult دسترسی نداریم، از این جهت به صورت مستقیم ViewViewComponentResult را ایجاد کرده‌ایم و مدلی که قرار است که به ویوو کامپوننت پاس داده شود را مقداردهی کرده‌ایم.<br/> </div> <div> <b> <br/> </b> </div> <div> <b>محل تعریف Viewها<br/> </b> </div> <div>Viewهای کنترلر و همچنین ویووکامپوننت مانند روش فوق قابل ترکیب نیستند؛ در نتیجه نیازی به تغییر هیچکدام از ویووها نخواهیم داشت.</div> <div> <div align="left" dir="ltr" style="direction: ltr;"> </div> <div align="left" dir="ltr" style="direction: ltr;">

 </div> <br/> </div> <div> <b>نکته</b>: دقت داشته باشید که ویجت نمایش لیست کاربران که پیشتر به صورت مستقل از عملکرد یک اکشن متد کار می‌کرده، قرار نیست جایگزین لیست کاربران (اکشن متد Index درون کنترلر UserManager) شود؛ یعنی به صورت مستقل از آن عمل میکند. هدف بیشتر قرار دادن View Component موردنظر درون کنترلر UserManager است.</div> </div></div>
