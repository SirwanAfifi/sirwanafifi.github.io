<div class="postBody"><div> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">همانطور که <a href="https://www.dntips.ir/post/2356">عنوان شد</a> به ماژول‌های داخلی، فضاهای نام (namespace) گفته می‌شود. بنابراین از namespaceها نیز جهت مدیریت و ساماندهی پروژه‌های بزرگ با تعداد فایل‌های زیاد استفاده می‌شود. در واقع یک namespace حالت ساده‌تری از یک ماژول است؛ یعنی برای بارگذاری آن در مرورگر نیاز به loader خاصی نیست. بنابراین در پروژه‌هایی با مقیاس کوچکتر استفاده از namespaceها، انتخاب بهتری است. همچنین یکی از مزیت‌های مهم namespace جلوگیری از شلوغ شدن global scope است.  </p> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;"> <br/> </p> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;"> <b>نحوه‌ی تعریف namespace در TypeScript</b> <b> </b> <br/> </p> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">برای ایجاد یک namespace کافی است از کلمه کلیدی namespace استفاده کنیم: <br/> </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="TypeScript" name="code">namespace Membership {&#10;    export function AddMember(name: string) {&#10;        // add a new member&#10;    }&#10;}</pre>
 </div> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">در کد فوق یک namespace را با نام Membership تعریف کرده‌ایم. درون این namespace می‌توانیم کدهای خود را بنویسیم. به عنوان مثال در کد فوق یک تابع را با نام AddMember درون آن تعریف کرده‌ایم و با استفاده از کلمه‌ی کلیدی <a href="https://www.dntips.ir/post/2356">export</a> این تابع را در معرض دید مصرف کننده قرار داده‌ایم. لازم به ذکر است که یک namespace می‌تواند به صورت nested (تودرتو) نیز استفاده شود. اما باید توجه داشته باشید که برای داشتن چنین قابلیتی باید از export نیز قبل از کلمه‌ی کلیدی namespace استفاده شود:  <br/> </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="TypeScript" name="code">namespace Membership {&#10;    export function AddMember(name: string) {&#10;        // add a new member&#10;    }&#10;    &#10;    export namespace Cards {&#10;        export function IssueCard(memberNumber: number) {&#10;            // issue new card&#10;        }&#10;    }&#10;}</pre>
 </div> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">همانطور که مشاهده می‌کنید، درون یک nested namespace نیز می‌توانیم اشیاء را توسط کلمه‌ی کلیدی export در معرض دید مصرف کننده قرار دهیم.</p> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;"> <b> <br/> </b> </p> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;"> <b>نحوه‌ی استفاده از namespaceها در TypeScript  </b> <br/> </p> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">برای استفاده از کدهای مثال قبل، در یک فایل دیگر می‌توانیم به صورت زیر یک ارجاع را به namespace مربوطه داشته باشیم:</p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="TypeScript" name="code">/// &lt;reference path="membership.ts" /&gt;</pre>
 </div> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">اکنون درون ادیتور، به صورت کامل به اشیاء export شده‌ی توسط فضای نام Membership دسترسی خواهید داشت. لازم به ذکر است به این نوع ارجاع، Triple-Slash References نیز گفته می‌شود. مزیت دیگر این روش این است که کامپایلر TypeScript ارجاعات را نیز کامپایل می‌کند.</p> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">برای استفاده از اشیاء مربوط به namespace ارجاع داده شده نیز باید از سینتکس نقطه استفاده کرد:</p> <div align="left" dir="ltr" style="direction: ltr;"> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="CSharp" name="code">Membership.AddMember('Garrett');&#10;Membership.Cards.IssueCard(500);</pre>
 </div> </div> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">نکته‌ایی که در اینجا وجود دارد این است که کامپایلر TypeScript به صورت پیش‌فرض فایل‌های ارجاع داده شده را به فایل‌های جداگانه‌ایی کامپایل خواهد کرد و فرض را بر این خواهد گذاشت که هر کدام از فایل‌های کامپایل شده قرار است به ترتیب استفاده از آنها درون صفحه استفاده شوند. برای تولید یک فایل واحد می‌توانید از فلگ outFile استفاده کنید. با کمک این فلگ تمامی ارجاعات، بر اساس ترتیب استفاده از آنها، به یک فایل واحد تبدیل خواهند شد. جهت درک بهتر موضوع، یک فایل را با نام utilityFunctions.ts با محتویات زیر ایجاد کنید: </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="TypeScript" name="code">namespace Utility {&#10;    export namespace Fees {&#10;        export function CalculateLateFee(daysLate: number): number {&#10;            return daysLate * .25;&#10;        }&#10;    }&#10;    export function MaxBooksAllowed(age: number): number {&#10;        if (age &lt; 12) {&#10;            return 3;&#10;        } else {&#10;            return 10;&#10;        }&#10;    }&#10;    function privateFunc(): void {&#10;        console.log('This is private....');&#10;    }&#10;}</pre>
 </div> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">در کد فوق یک namespace با نام Utility ایجاد کرده‌ایم سپس یک namespace دیگر و همچنین یک تابع را درون آن export کرده‌ایم. اکنون می‌خواهیم از این فضای نام درون یک فایل دیگر با نام app.ts استفاده کنیم. برای اینکار دورن فایل app.ts با استفاده از Triple-Slash یک ارجاع را به فضای نام عنوان شده اضافه کنید:</p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="CSharp" name="code">/// &lt;reference path="utilityFunctions.ts" /&gt;</pre>
 </div> <p style=" background-image: initial; background-attachment: initial; background-size: initial; background-origin: initial; background-clip: initial; background-position: initial; background-repeat: initial;">اکنون می‌توانیم از Intellisense مربوط به VS Code جهت دسترسی به اعضای فضای نام Utility استفاده کنیم:</p> <p style="margin-left: auto; margin-right: auto;"> <img src="/img/dntips/20bcd7c4690705bd3d40.jpg" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p style="margin-left: auto; margin-right: auto;">لازم به ذکر است برای namespace مربوطه می‌توانیم alias نیز جهت دسترسی سریع‌تر، تعریف کنیم:</p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="TypeScript" name="code">/// &lt;reference path="utilityFunctions.ts" /&gt;&#10;import util = Utility.Fees;&#10;let fee = util.CalculateLateFee(10);&#10;console.log(`Fee: ${fee}`);</pre>
 </div> <p style="margin-left: auto; margin-right: auto;">توسط فرمان زیر نیز می‌توانیم فایل فوق را به راحتی کامپایل کنیم:</p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="TypeScript" name="code">tsc --target ES5 app.ts</pre>
 </div> <p style="margin-left: auto; margin-right: auto;">با فرمان فوق، فایل app.js به همراه تمامی فایل‌های ارجاع داده شده‌ی درون آن نیز کامپایل خواهند شد.</p> <p style="margin-left: auto; margin-right: auto;">اکنون اگر بخواهیم توسط node فایل app.js را اجرا کنیم، با خطای ReferenceError: Utility is not defined مواجه خواهیم شد. دلیل آن نیز این است که node سعی در لود کردن فایل به صورت یک ماژول دارد و از آنجائیکه ما از namespace استفاده کرده‌ایم، فضای نام Utility توسط node قابل شناسنایی نمی‌باشد. اما درون یک صفحه‌ی HTML با قرار دادن فایل utilityFunctions.js و سپس app.js مشکلی نخواهیم داشت. برای حل این مورد در node کافی است از نکته‌ی یکی کردن فایل‌ها استفاده کنیم: </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="TypeScript" name="code">tsc --target ES5 app.ts --outFile out.js</pre>
 </div> <p style="margin-left: auto; margin-right: auto;">در این‌حالت فایل‌ها به ترتیب استفاده، با هم ادغام شده و تبدیل به یک فایل با نام out.js خواهند شد.</p> </div></div>
