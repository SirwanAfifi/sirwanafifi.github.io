<div class="postBody">در قسمت <a href="/blog/fa/dntips-3266/">قبل</a> توابعی را که برای تغییر دیتای JSON مورد استفاده قرار میگیرند، بررسی کردیم. در ادامه به بررسی روش‌های تبدیل یک دیتای غیر JSON به خروجی JSON و بلعکس خواهیم پرداخت. <div> <br/> </div> <div>کوئری‌هایی که تا اینجا نوشته‌ایم، بر روی یک فیلد از نوع JSON بودند؛ اما این امکان را نیز داریم که از توابع JSON بر روی فیلدهای غیر JSON نیز استفاده کنیم. به عنوان مثال جدول کاربران و بلاگ‌پست را در نظر بگیرید که به این صورت تعریف شده‌اند: </div> <div> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">CREATE TABLE Users (&#10;  id INT NOT NULL AUTO_INCREMENT,&#10;    first_name VARCHAR(255) NOT NULL,&#10;    last_name VARCHAR(255) NOT NULL,&#10;    email VARCHAR(255) NOT NULL,&#10;    gender ENUM('Male', 'Female') NOT NULL,&#10;    PRIMARY KEY (id)&#10;);&#10;&#10;CREATE TABLE BlogPosts (&#10;    id INT NOT NULL AUTO_INCREMENT,&#10;    title VARCHAR(255) NOT NULL,&#10;    user_id INT NOT NULL,&#10;    KEY user_id (user_id),&#10;    CONSTRAINT `blogposts_ibfk_1` FOREIGN KEY (user_id)&#10;        REFERENCES Users (id),&#10;    PRIMARY KEY (id)&#10;)</pre>
 </div> <br/> </div> <div>جداول فوق یا یکسری دیتای fake پر شده‌اند. اکنون فرض کنید میخواهیم لیست کاربران را به همراه بلاگ‌پست‌هایشان، کوئری بگیریم:  <br/> </div> <div> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">SELECT &#10;    U.id,&#10;    CONCAT_WS(' ', U.first_name, U.last_name) AS FullName,&#10;    BP.title&#10;FROM&#10;    Users AS U&#10;        JOIN&#10;    BlogPosts AS BP ON U.id = BP.user_id;</pre>
 </div> <br/> </div> <div>همانطور که میدانید خروجی موردانتظار در یک دیتابیس رابطه‌ایی به صورت سطر و ستون است:  <br/> </div> <div> <br/> </div> <div> <p style="margin-left: auto; margin-right: auto;"> <img src="/img/dntips/f55961c8fe35460dff80.png" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;"> <b>تبدیل یک ساختار Relational به JSON  </b> <br/> </p> <p style="margin-left: auto; margin-right: auto;">میتوانیم خروجی موردنظر را در قالب JSON نیز کوئری بگیریم:  <br/> </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">SELECT &#10;    JSON_OBJECT('id',&#10;            U.id,&#10;            'user',&#10;            CONCAT_WS(' ', U.first_name, U.last_name),&#10;            'title',&#10;            BP.title)&#10;FROM&#10;    Users AS U&#10;        JOIN&#10;    BlogPosts AS BP ON U.id = BP.user_id;</pre>
 </div> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;">به عنوان مثال میتوانیم لیست کاربران را به همراه بلاگ پست‌هایشان، اینگونه کوئری بگیریم:  <br/> </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">SELECT &#10;    JSON_OBJECT('user',&#10;            CONCAT_WS(' ', U.first_name, U.last_name),&#10;            'blog_posts',&#10;            JSON_ARRAYAGG(JSON_OBJECT('id', BP.id, 'title', BP.title))) AS JSON&#10;FROM&#10;    Users AS U&#10;        JOIN&#10;    BlogPosts AS BP ON U.id = BP.user_id&#10;GROUP BY U.id;</pre>
 </div> <p style="margin-left: auto; margin-right: auto;">خروجی کوئری فوق اینچنین خواهد بود:</p> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;"> <img src="/img/dntips/a9581e68e53a7e3ed4e9.png" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;"> <b>تبدیل یک ساختار JSON به Relational  <br/> </b> </p> <p style="margin-left: auto; margin-right: auto;"> همچنین میتوانیم یک ساختار JSON را به صورت Relational تبدیل کنیم. اینکار توسط تابع JSON_TABLE قابل انجام است. کاری که این تابع انجام میدهد، ایجاد یک جدول موقت و کپی کردن دیتای موردنظر درون آن است. فرض کنید ساختار JSON زیر را به اینصورت درون دیتابیس ذخیره کرده‌ایم: <br/> </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="JScript" name="code">{&#10;  "id": "1",&#10;  "new": false,&#10;  "sku": "asdf123",&#10;  "tag": ["fashion", "men", "jacket", "full sleeve"],&#10;  "name": "Lorem ipsum jacket",&#10;  "image": [&#10;    "/assets/img/product/fashion/1.jpg",&#10;    "/assets/img/product/fashion/3.jpg",&#10;    "/assets/img/product/fashion/6.jpg",&#10;    "/assets/img/product/fashion/8.jpg",&#10;    "/assets/img/product/fashion/9.jpg"&#10;  ],&#10;  "price": 12.45,&#10;  "rating": 4,&#10;  "category": ["fashion", "men"],&#10;  "discount": 10,&#10;  "offerEnd": "October 5, 2020 12:11:00",&#10;  "saleCount": 54,&#10;  "description": {&#10;    "fullDescription": "Sed ut perspiciatis unde omnis iste natus error sit voluptatem accusantium doloremque laudantium, totam rem aperiam, eaque ipsa quae ab illo inventore veritatis et quasi architecto beatae vitae dicta sunt explicabo.  </div> <p style="margin-left: auto; margin-right: auto;">اکنون میخواهیم چنین خروجی‌ای داشته باشیم:  <br/> </p> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;"> <img src="/img/dntips/be89a03cc33098a2c66e.png" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;">کوئری موردنیاز برای تهیه خروجی فوق اینچنین خواهد بود:  <br/> </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">SELECT newTable.* &#10;FROM experiments.productMetadata,&#10;JSON_TABLE(&#10;data,&#10;    "$" COLUMNS (&#10;id INT PATH "$.id",&#10;        new CHAR(5) PATH "$.new",&#10;        sku CHAR(20) PATH "$.sku",&#10;        price FLOAT PATH "$.price",&#10;        rating FLOAT PATH "$.rating",&#10;        name CHAR(255) PATH "$.name",&#10;        discount FLOAT PATH "$.discount",&#10;        offerEnd TEXT PATH "$.offerEnd",&#10;        saleCount INT PATH "$.saleCount",&#10;        description TEXT PATH "$.description.shortDescription"&#10;    )&#10;) AS newTable;</pre>
 </div> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;">تابع JSON_TABLE دو ورودی نیاز خواهد داشت؛ ورودی اول ستون JSONی است که میخوایم از آن کوئری بگیریم. ورودی دوم با تعیین path شروع خواهد شد. از آنجائیکه محتوای داخل ستون data به صورت آبجکت ذخیره شده‌است، از $ استفاده کرده‌ایم که به معنای داکیومنت جاری است. سپس توسط کلمه کلیدی COLUMNS ساختار جدول موقت‌مان را تعریف خواهیم کرد. این ساختار به صورت یک آرگومان به COLUMNS ارسال خواهد شد و شبیه به ساختار CREATE TABLE است؛ با این تفاوت که بعد از تعریف نوع داده‌ای هر ستون باید مسیر رسیدن به مقدار موردنظر را نیز تعیین کنیم که در واقع همان سینتکس pathی است که در مثالهای قبل نیز بررسی کردیم. به عنوان مثال برای رسیدن به مقدار پراپرتی name، مسیر را به صورت name.$ نوشته‌ایم. این path از آرایه نیز پشتیبانی میکند؛ مثلاً برای دسترسی به عنصر اول آرایه tag کافی است اینگونه عمل کنیم:  <br/> </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">tag CHAR(20) PATH "$.tag[0]"</pre>
 </div> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;">همچنین تابع JSON_TABLE، از ساختارهای تودرتو نیز پشتیبانی میکند. به عنوان مثال برای داشتن مقادیر tag, category, image در خروجی میتوانیم از کلمه کلیدی NESTED استفاده کنیم:  <br/> </p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">SELECT newTable.* &#10;FROM experiments.productMetadata,&#10;JSON_TABLE(&#10;data,&#10;    "$" COLUMNS (&#10;id INT PATH "$.id",&#10;        new CHAR(5) PATH "$.new",&#10;        sku CHAR(20) PATH "$.sku",&#10;        price FLOAT PATH "$.price",&#10;        rating FLOAT PATH "$.rating",&#10;        NESTED PATH '$.tag[*]' COLUMNS (tag TEXT PATH '$'),&#10;        name CHAR(255) PATH "$.name",&#10;        discount FLOAT PATH "$.discount",&#10;        offerEnd TEXT PATH "$.offerEnd",&#10;        saleCount INT PATH "$.saleCount",&#10;        description TEXT PATH "$.description.shortDescription",&#10;        NESTED PATH '$.image[*]' COLUMNS (image TEXT PATH '$'),&#10;        NESTED PATH '$.category[*]' COLUMNS (category TEXT PATH '$')&#10;    )&#10;) AS newTable;</pre>
 </div>
کوئری فوق به ازای هر آیتم از آرایه‌های فوق، یک ردیف جدید اضافه خواهد کرد:  <br/> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;"> <img src="/img/dntips/222df4d6caf823d59337.png" style="display: block; margin-left: auto; margin-right: auto; cursor: default;"/> </p> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;">درون COLUMNS میتوانیم یک name FOR ORDINALITY نیز تعیین کنیم. این فیلد دقیقاً مشابه AUTO INCREMENT در ساختار CREATE TABLE میباشد. به این معنا که به ازای هر آیتم فیلد nested، یک واحد اضافه خواهد شد. از آن میتوانیم به عنوان rowId برای آیتم آرایه استفاده کنیم:</p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">NESTED PATH '$.category[*]' COLUMNS (categoryRowId FOR ORDINALITY, category TEXT PATH '$')</pre>
 </div> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;">همچنین از ON EMPTY برای پراپرتی‌هایی که در ساختار JSON وجود ندارند نیز میتوانیم استفاده کنیم. به عنوان مثال در کوئری زیر گفته‌ایم در صورت عدم وجود price، یک مقدار پیش‌فرض باید نمایش داده شود و همچنین در صورت عدم وجود name، یک خطا در خروجی نمایش داده شود:</p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">name CHAR(255) PATH "$.name" ERROR ON EMPTY,&#10;price FLOAT PATH "$.price" DEFAULT "0" ON EMPTY,</pre>
 </div> <p style="margin-left: auto; margin-right: auto;"> <br/> </p> <p style="margin-left: auto; margin-right: auto;">همچنین میتوانیم مقدار NULL را در صورت عدم وجود name ست کنیم:</p> <div align="left" dir="ltr" style="direction: ltr;">
<pre language="Sql" name="code">name CHAR(255) PATH "$.name" NULL ON EMPTY,</pre>
