Public developer resources

Sirwan Afifi developer portal_

Use the public content API and discovery files to find Sirwan Afifi's writing, site metadata, feeds, and machine-readable documentation. Everything here is read-only and available without an account.

Quickstart

Fetch site identity and discovery links with one unauthenticated GET request:

curl --fail --silent https://sirwan.info/api/site.json

The response is JSON. For a complete post index, request/api/posts.json.

Authentication and API keys

No authentication is required and no API keys are issued. The API has no write operations, private records, webhooks, or user accounts. If a future endpoint changes that contract, its authentication scheme will be added to the OpenAPI document before release.

These resources are provided for discovery and lightweight personal use. There is no uptime SLA. Clients should cache responses, identify themselves responsibly, and follow standard HTTP status semantics.
